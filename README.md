## 📖 Executive Summary & What Has Happened So Far

Joyful Hearing & Speech Clinic is a premier audiology and speech-language therapy center in Lucknow. This repository contains the complete frontend codebase, custom digital assets, brand device integrations, and an extensive clinical blog library (33 published long-form articles).

### 🚀 Key Milestones & Recent Developments:
1. **Core Website & Diagnostic Pages**:
   - High-converting Homepage with interactive hearing self-assessment quiz.
   - Clinical service pages covering Audiometry, Hearing Aid Dispensing, Speech Therapy, Tinnitus Management, Newborn Screening (OAE/BERA), and Cochlear Implant Rehabilitation.
   - Complete technical SEO, schema markup (JSON-LD), responsive UI, OpenGraph metadata, and accessibility enhancements.

2. **World-Class Hearing Aid Brands Architecture (`brands.html`)**:
   - Reordered, client-approved 5-brand showcase:
     1. **ReSound GN** (Flagship: *ReSound Vivia* & *NEXIA* with Auracast & All-Access Directionality)
     2. **Signia** (Flagship: *Integrated Xperience* & *Own Voice Processing - OVP*)
     3. **Widex** (Flagship: *Widex Moment* & *PureSound ZeroDelay* technology)
     4. **Phonak** (Flagship: *AutoSense OS* & *Roger Wireless* technology)
     5. **Starkey** (Flagship: *Genesis AI* & deep neural network noise management)
   - Custom high-fidelity brand device logos and descriptions.
   - Synchronized navigation menus across all site pages to ensure seamless access to `brands.html`.

3. **Extensive 33-Article Clinical Blog Library (`blog.html`)**:
   - Built a content engine with rich typography, author credentials, WhatsApp/Call booking CTAs, custom imagery extracted from clinical source documentation, and responsive card layouts.
   - Resolved title/schema template inheritance bugs ensuring all 33 articles have distinct, crawlable H1 tags and structured data.

## 🛠️ Technology Stack & Architecture

- **Markup & Styling**: Semantic HTML5, Tailwind CSS (utility-first styling), Google Fonts (*Plus Jakarta Sans* & *Cabinet Grotesk*).
- **Icons & Graphics**: Phosphor Icons, FontAwesome, and custom brand logos.
- **Interactivity**: Pure Vanilla JavaScript (modular mobile navigation drawers, interactive quiz calculators, dynamic brand filtering, modal dialogues).
- **SEO & Performance**: Preconnect CDN links, zero bloated npm frameworks, lightweight static pages with immediate First Contentful Paint (FCP).
- **Automated Deployment**: GitHub Actions workflow deploying to Hostinger via automated FTP upon push to `main`.

## 💻 Local Development & Contribution

Since the site is built on pure static web standards, no compilation or bundler step is needed:

```bash
# 1. Clone repository
git clone https://github.com/flowxoperations-code/Joyful-Hearing.git

# 2. Navigate to project root
cd Joyful-Hearing

# 3. Open index.html directly or serve locally via python
python3 -m http.server 8000
```
Visit `http://localhost:8000` in your web browser.

## 🚢 Deployment Configuration

Continuous deployment is handled by `.github/workflows/deploy.yml`. When changes are merged to the `main` branch, GitHub Actions transfers modified assets directly to Hostinger's `public_html`.

### Required GitHub Secrets:
- `FTP_SERVER`: Hostinger FTP host URL
- `FTP_USERNAME`: Authorized FTP username
- `FTP_PASSWORD`: Authorized FTP account password
- `FTP_SERVER_DIR`: Destination directory (`public_html`)
